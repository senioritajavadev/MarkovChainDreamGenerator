## Dream Generator with Markov Chains

A program for generating dreams based on a corpus of existing texts using Markov chains. Implemented in pure Python, without the use of library components.

## 📋 Description

The generator analyzes the structure of uploaded dream descriptions and creates new ones by combining words and phrases based on statistical phenomena. The more source data, the more coherent the results.

## 🚀 Features

- Dream generation based on a text corpus
- Customizable Markov chain order (analysis depth)
- Seed word generation support
- Interactive experimentation mode
- Model statistics
- Adjustable minimum and maximum dream description lengths

## 🔧 Requirements

- Python 3.6 or higher
- Only standard Python libraries (random, re, collections, argparse)

## Генератор снов на марковских цепях

Программа для генерации сновидений на основе корпуса существующих текстов с использованием цепей Маркова. Реализована на чистом Python без использования сторонних библиотек.

## 📋 Описание

Генератор анализирует структуру загруженных описаний снов и создает новые, комбинируя слова и фразы на основе статистических закономерностей. Чем больше исходных данных, тем более связными получаются результаты.

## 🚀 Возможности

- Генерация снов на основе текстового корпуса
- Настройка порядка цепи Маркова (глубины анализа)
- Поддержка начального слова для генерации
- Интерактивный режим для экспериментов
- Статистика модели
- Регулировка минимальной и максимальной длины описания сна

## 🔧 Требования

- Python 3.6 или выше
- Только стандартные библиотеки Python (random, re, collections, argparse)
